Assignment 1: Create a Simple procfs Entry
--------------------------------------------------
Objective:
Create a kernel module that creates a file under /proc.

Requirements:
- Create /proc/myproc
- When read, display:
  Hello from procfs!
- Remove the proc entry when the module is unloaded.

Expected Output:
$ cat /proc/myproc
Hello from procfs!


==================================================================

Assignment 2: procfs Read/Write
--------------------------------------------------
Objective:
Implement both read and write operations.

Requirements:
- Create /proc/message
- Support writing:
  echo "Linux Kernel" > /proc/message
- Reading should display:
  Linux Kernel
- Store the latest message in kernel memory.

Expected Output:
$ echo "Linux Kernel" > /proc/message
$ cat /proc/message
Linux Kernel


==================================================================

Assignment 3: Counter Using procfs
--------------------------------------------------
Objective:

Requirements:
Each time the proc file is read, increment the counter.

Expected Output:

$ cat /proc/counter
2

$ cat /proc/counter
3

Assignment 6: Create a sysfs Attribute
--------------------------------------------------
Objective:
Create a sysfs attribute.

Requirements:
Create:
/sys/kernel/mydriver/value

Default value:
100

Support:
cat value

Expected Output:
$ cat value
100

$ echo 200 > value

$ cat value
200
